## 🛠 [Step 0] Environment Setup & Theoretical Background

### 3-Step Autonomous Driving Core Process
- **Perception**: Digitizing the surroundings via sensor fusion (RTK-GNSS, LiDAR, Vision).
- **Decision**: Generating Global Path Planning (CPP) and computing local obstacle avoidance based on collected data.
- **Control**: Precision manipulation of actuators (steering, throttle/brake, implements) via Drive-by-Wire systems.

### Path Tracking Control Basics
- **Reference**: The baseline path the tractor must follow (generated by Coverage Path Planning).
- **Cross-Track Error (CTE)**: The perpendicular distance error between the tractor's current position and the reference line.
- **Pure Pursuit Algorithm**: Deriving the steering angle by targeting a point (look-ahead distance, $L_d$) ahead on the reference line from the center of the tractor's rear axle.
