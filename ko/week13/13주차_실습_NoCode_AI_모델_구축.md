# 13주차 실습: No-Code AI를 활용한 작물/잡초 판독 모델 구축

## 📺 참고 영상 (Reference Video)
- **추천 시청 자료**: [Google Teachable Machine 사용법 가이드](https://youtu.be/T2qQGqZxkD0)
- 실습 전 영상을 시청하여 데이터 수집 및 학습 인터페이스를 익혀두세요.

---

## 🎯 실습 개요
- **목표**: 딥러닝 아키텍처(CNN)의 복잡한 구현 과정을 생략하고, 웹 브라우저 기반의 노코드(No-code) 도구를 활용하여 작물과 잡초를 실시간으로 구분하는 AI 모델을 제작함
- **실습 형태**: Google Teachable Machine을 이용한 이미지 분류(Image Classification) 모델 학습
- **핵심 학습 개념**: 클래스 정의, 데이터 수집(Webcam), 하이퍼파라미터(Epoch, Batch), 실시간 추론(Inference)

---

## 🛠 [Step 1] 실습 준비 및 환경 접속
1. 노트북의 **웹캠(Webcam)**이 정상 작동하는지 확인합니다.
2. 크롬(Chrome) 브라우저를 열고 [Teachable Machine](https://teachablemachine.withgoogle.com/train/image) 사이트에 접속합니다.
3. `Get Started` 버튼을 누르고 `Image Project` -> `Standard image model`을 선택합니다.

---

## 📸 [Step 2] 데이터셋(Dataset) 구축
농업 AI의 성능은 데이터의 질(Quality)에 의해 결정됩니다. 아래의 세 가지 클래스를 정의하고 데이터를 수집하세요.

1. **Class 1 (정상 작물)**: 
   - 실제 식물이나 화초 잎사귀를 웹캠 앞에 비춥니다.
   - `Hold to Record` 버튼을 눌러 다양한 각도, 거리, 방향에서 약 200장 이상의 이미지를 캡처합니다.
2. **Class 2 (잡초 대용)**: 
   - 잡초로 가정할 물체(예: 색종이 모형, 펜, 또는 다른 종류의 잎)를 준비합니다.
   - 작물과 명확히 구분되는 특징이 드러나도록 데이터를 수집합니다.
3. **Class 3 (배경)**: 
   - 아무 물체도 없는 빈 배경을 촬영합니다. (모델이 빈 화면을 특정 클래스로 오인하지 않게 하기 위함)

---

## ⚙️ [Step 3] 모델 학습 (Training)
수집된 데이터를 바탕으로 신경망을 훈련시키는 과정입니다.

1. `Train Model` 버튼을 클릭합니다.
2. **고급(Advanced) 설정 조절**:
   - **Epochs**: 전체 데이터를 몇 번 반복 학습할지 설정합니다. (기본 50)
   - **Batch Size**: 한 번에 학습할 이미지 묶음의 크기입니다.
3. 학습이 진행되는 동안 브라우저 탭을 닫거나 다른 창으로 이동하지 마세요.

---

## 🎯 [Step 4] 실시간 추론 및 성능 테스트
학습이 완료되면 우측 `Preview` 창에 실시간 웹캠 화면이 나타납니다.

1. **인식률 확인**: 작물과 잡초 모델을 번갈아 비춰보며 하단의 확률 막대그래프(Probability)가 정확하게 움직이는지 확인합니다.
2. **사각지대(Edge Case) 테스트**: 
   - 손으로 잎의 일부를 가려보세요. (오클루전 상황)
   - 조명을 끄거나 어둡게 하여 인식률 변화를 관찰하세요.
   - 학습시키지 않은 새로운 물체를 보여주고 모델이 어떻게 판단하는지 확인하세요.

---

## 💻 [Step 5] [심화] YOLO 실시간 객체 탐지 체험 (`step0_yolo_vision_test.py`)
강의 2교시에서 배운 최첨단 객체 탐지 알고리즘인 YOLOv8을 파이썬 환경에서 즉각 실행해봅니다. 별도의 학습 없이도 화초(Potted plant) 등을 인식하는 인공지능의 성능을 확인하세요.

1. 터미널에서 필요 라이브러리를 설치합니다.
   ```bash
   pip install ultralytics opencv-python
   ```
2. `step0_yolo_vision_test.py`를 실행하고 웹캠 앞에 다양한 물체를 비춰봅니다.

---

## 💻 [Step 6] [심화] 학습 모델 파이썬 이식 (`step1_tm_model_load.py`)
티쳐블 머신에서 만든 "노코드 모델"을 실제 "파이썬 코드"로 가져와 구동하는 방법을 익힙니다.

1. 티쳐블 머신 우측 상단의 `Export Model` 버튼을 클릭합니다.
2. `Tensorflow` -> `Keras`를 선택하고 `Download my model`을 누릅니다.
3. 다운로드된 압축파일 안의 `keras_model.h5`와 `labels.txt` 파일을 현재 실습 폴더(`week13/`)로 복사합니다.
4. `step1_tm_model_load.py`를 실행하여 본인이 만든 모델이 파이썬에서도 정상 작동하는지 확인합니다.

---

## 📝 [Step 7] 결과 분석 및 보고서 작성
실습 결과를 바탕으로 [13주차 실습 결과 보고서]를 작성합니다. 다음 질문에 대한 답을 반드시 포함하세요.

- **데이터 편향성**: 배경에 특정한 물체(예: 내 손가락)가 계속 찍혔을 때, 그 물체만 보고 잡초로 판단하는 현상이 발생했는가?
- **일반화 성능**: 내가 학습시킨 식물과 '비슷하게 생긴' 다른 식물을 보여주었을 때 모델이 정답을 맞히는가?
- **현장 적용**: 이 모델을 실제 자율주행 방제 로봇(See & Spray)에 탑재한다면, 어떤 센서나 조명 장치가 추가로 필요하겠는가?

---

### 💡 팁 (Tips)
- 모델의 성능이 낮다면 데이터를 더 많이 수집하거나, 배경을 더 단순하게 바꾸어 보세요.
- Teachable Machine에서 완성된 모델은 `Export Model` 버튼을 통해 **TensorFlow.js**나 **Keras(.h5)** 형태로 다운로드하여 실제 앱이나 하드웨어에 탑재할 수 있습니다.
